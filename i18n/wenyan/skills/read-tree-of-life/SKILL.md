# 讀生命之樹

行卡巴拉之生命樹（Etz Chaim）——定十質、追廿二徑、識其象，於四界三柱之構中行冥想。

## 用時

- 欲察一質之屬與其聖名
- 欲解諸質之構相連（徑、三角、柱）
- 學四界（Atzilut 至 Assiah）及其於樹之層
- 欲行繫於樹上某處之冥想
- 追二質間之徑，需其希伯來字、塔羅、元素之對
- 用樹為象之圖以解一念或一系

## 入

- **必要**：欲察之質、徑或構之元（如 Tiferet、Hod 與 Yesod 間之徑、嚴柱）
- **可選**：傳承之擇（古猶太卡巴拉、赫密斯卡巴拉、比較）
- **可選**：深淺之等（概覽、詳習、冥想）
- **可選**：當下之境或樹宜照之問

## 法

### 第一步：定欲察之質或徑

定樹上之具體位與其本識。

            Keter (1)
           /    |    \

1. 命用者所欲察之質、徑或構之元
2. 定其於樹圖之位——何柱、何界、何三角
3. 記其號（質為 1-10；徑古傳為 11-32）
4. 識其傳承之境：古典（Cordovero、Luria）或赫密斯（Golden Dawn）

得：察始之位明於樹上。用者可於整構中心定其元。

敗則：若用者所請含混（如「言樹之事」），先示三柱十質之概，後問深察何處。

1. 為所擇之質填屬之表
2. 記聖名與其義（每質皆有獨之神名）
3. 識繫其質之大天使與天使之團
4. 錄星與色之對（記傳承：猶太或赫密斯）
5. 述德（衡時之表）與弊（過或不及）

得：質之全屬之像。用者解質所表、行中如何呼之、其與他象系之繫。

敗則：若用者為對所淹，獨示名、譯、號、柱、一句之要。請而後詳之。

1. 列連於所察之質之諸徑
2. 各徑記：希伯來字、向（自/至）、其對
3. 識越深淵之徑（介於至上與下質間）——此乃要關
4. 赫密斯之塔羅對與猶太卡巴拉之內容分記之
5. 觀其形：此質與何者最直接相通？

得：用者於境中見質——非孤立，乃由具體徑連於鄰，各徑載其象之重。

敗則：若徑之對令惑，專注於質之直鄰（連於何質）而不詳各字。用者備時再增字之對。

### 第四步：定於四界

置質或徑於四界之框，以解其顯之等。

```text
The Four Worlds (Olamot):

ATZILUT (Emanation) — World of Archetypes:
  Sephirot: Keter, Chokmah, Binah
  Nature: Divine will, pure emanation, undifferentiated
  Experience: Unity, source, the Ein Sof's first self-expression
  Soul level: Yechidah (unique essence) and Chayah (life force)

BRIAH (Creation) — World of Thrones:
  Sephirot: Chesed, Gevurah, Tiferet
  Nature: Creative intellect, archangelic, first differentiation
  Experience: Understanding, moral discernment, vision
  Soul level: Neshamah (divine soul, breath of God)

YETZIRAH (Formation) — World of Angels:
  Sephirot: Netzach, Hod, Yesod
  Nature: Emotional/astral, angelic, formative patterns
  Experience: Feelings, imagination, dreams, astral perception
  Soul level: Ruach (spirit, intellectual soul)

ASSIAH (Action) — World of Making:
  Sephirot: Malkut (and the physical universe)
  Nature: Material, elemental, the manifest world
  Experience: Sensory reality, embodied life, physical action
  Soul level: Nephesh (animal soul, vital force)

Key Principle: Every sephira exists in ALL four worlds simultaneously.
The "world" assignment above indicates where each sephira's PRIMARY
influence is felt, but Tiferet-of-Atzilut is different from
Tiferet-of-Assiah — same position, different level of reality.
```

1. 識質主行於何界
2. 記繫於該界之魂等（Yechidah、Chayah、Neshamah、Ruach、Nephesh）
3. 述質之質於各界之等如何異顯
4. 若察徑，記其留於一界或越界

得：用者解樹非平而為層——同構於四等實在重複，所察之質有具體「本界」並於諸等皆有顯。

敗則：若四界之框過抽象，簡之：Atzilut = 神、Briah = 智、Yetzirah = 情、Assiah = 物。問用者欲專何等。

### 第五步：冥想之行

引一冥想或沉思，繫於具體之質或徑。

1. 立其境：以一句述質之核
2. 議姿與息（簡：坐、目閉、自然之息）
3. 示一觀想：想質為其色之球，於其身對應之點
4. 設一沉思之問繫於質之德弊：
   - Chesed：「吾於何處慷慨予之？於何處予以避不適？」
   - Gevurah：「吾於何處立必要之界？於何處嚴致害？」
   - Tiferet：「吾生中美在何處？於何處避和諧？」
   - （各質宜調之）
5. 終以簡誦或肯定之語用質之聖名（默或聲）
6. 返常識，攜一具體之見或意

得：用者自智習至體驗質。冥想將抽象之象繫於己思。

敗則：若冥覺強或假，代以記誌：書五分鐘論質之質如何現於當下之生。書反省以異模達相似之整。

## 驗

- [ ] 已定具體之質或徑於樹上之位（柱、界、三角）
- [ ] 已示核屬（名、號、聖名、大天使、對）
- [ ] 連之徑已追，附希伯來字之對
- [ ] 已議四界之境（何界、何魂等）
- [ ] 已示冥想或反省之題
- [ ] 對異時記其傳承（猶太對赫密斯）

## 陷

- **混傳承**：Golden Dawn 之徑對異於 Gra、異於 Ari（Isaac Luria）。必明用何系
- **視樹為靜**：樹乃動——質相交，徑載氣於其間。示之為活系，非檔櫃
- **略 Da'at**：「隱質」（Da'at／知）介於至上三角與下七之間。其非同義之質而為越深淵之關
- **過依對**：對之表為圖，非地。助冥而不可代直觸質之質
- **忽其陰**：每質皆有弊（qliphotic 之殼）與德。獨示陽屬乃殘像
- **躁進深義**：樹之構似簡而深無極。先確基（十質、三柱），後引徑、界、深學
